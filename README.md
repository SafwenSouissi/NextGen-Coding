# 🌤️ Weather App

A responsive and modern **Weather App** built using **HTML**, **CSS**, and **JavaScript**. It fetches real-time weather data from a public API and displays the current conditions of any city you search for.


## 🌍 Features

- Real-time weather data (temperature, humidity, wind, etc.)
- City search functionality
- Weather icons and descriptions
- Responsive UI for mobile and desktop
- Error handling for invalid locations

## 🛠️ Tech Stack

- **HTML5** – Page structure
- **CSS3** – Layout and styling
- **JavaScript** – API integration and dynamic rendering
- **Weather API** – [OpenWeatherMap](https://openweathermap.org/api)

##🧠 How It Works
User enters a city name.

JavaScript fetches weather data using the API.

Data is displayed in the app interface with:

Temperature

Description (e.g., clear, cloudy)

humidity

Weather icon

Handles errors (e.g., city not found).
